OpenEpoch

A free real-time strategy game across six epochs — from clubmen to nuclear submarines. Rust + WebAssembly simulation, 3D WebGL2 rendering, zero downloads.

1 vs 1, directly between two browsers — no server. The host creates an invite code, the guest answers with a reply code (send them by chat or mail).
